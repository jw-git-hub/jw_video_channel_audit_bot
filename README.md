# @jw_video_channel_audit_bot

Аудит видеоканала в Telegram: присылаешь ссылку на YouTube-канал — получаешь отчёт словами о том, как часто
выходят видео, как их смотрят, какие они и куда описания ведут зрителя. Бот экосистемы `>jw_` — jw-dev.pro.

## Как устроено

```
ссылка на канал, @имя или видео → разбор в ID или имя (присланную ссылку бот не открывает)
    → кэш на сутки → YouTube Data API: канал → плейлист загрузок → видео пачками по 50
    → подсчёты: ритм, отдача, форматы, куда идёт зритель, вывод
    → статья: «Смотрю канал…» превращается в отчёт
```

- Python 3.12, aiogram 3.31 (Bot API 10.3), SQLite, Docker.
- Данные — только YouTube Data API v3 по ключу, без входа владельца канала. Из данных YouTube в базе — только ID
  и @имя канала, 20 дней.
- Одновременно — 3 аудита, очереди нет: аудит длится секунды.

## Разработка

```bash
git config core.hooksPath .githooks   # один раз в свежей копии: хук не пустит секрет в коммит
scripts/test.sh                       # тесты без сети; окружение — вне синхронизируемой папки
```

- Бот запускается только на сервере; на Маке — только тесты.
- Секреты — только в `.env` на сервере. Адреса и пути сервера в репозиторий не пишутся.
- Выкладка: `deploy/deploy.sh` (подробно — в памятке).
