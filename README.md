# @jw_video_channel_audit_bot

Аудит видеоканала в Telegram: присылаешь ссылку на YouTube-канал — получаешь отчёт словами о том, как часто
выходят видео, как их смотрят, какие они и куда описания ведут зрителя. Бот экосистемы `>jw_` — jw-dev.pro.
