# jw_video_channel_audit_bot — правила для сессий Claude

Бот @jw_video_channel_audit_bot: ссылка на YouTube-канал → отчёт словами. ТЗ — `docs/ТЗ.md`, план —
`docs/план.md`, памятка — `docs/эксплуатация.md`. Меняется утверждённое — сначала владельцу.

## Секреты — репозиторий публичный

- В свежей копии сразу: `git config core.hooksPath .githooks`. Нет gitleaks — `brew install gitleaks`.
- `.env` не читать, не печатать, не копировать; на Маке его нет — он только на сервере.
- Адрес, пользователь и пути сервера — только в `deploy/deploy.local.env` (вне git). В коде, документах и
  коммитах их нет.
- `HANDOFF.md` и `JOURNAL.md` — вне git: в них можно писать адреса и пути.
- Хук что-то нашёл — не обходить: разобраться. Секрет попал в коммит — стоп, сообщить владельцу: ключ
  перевыпускается.

## Данные YouTube

- Ключ — единственное, без чего бот не работает. Правила YouTube API — ТЗ, раздел 11.
- Названия, описания, @имена и цифры настоящих каналов не пишутся ни в код, ни в тесты, ни в документы, ни в
  `JOURNAL.md` и `HANDOFF.md`, ни в коммиты. Тестовые ответы — выдуманные.
- Только `channels.list`, `playlistItems.list`, `videos.list`. Без `search.list`, без `UUSH`/`UULF`, без страниц
  youtube.com.

## Работа

- Бот запускается только на сервере. На Маке — только `scripts/test.sh` (тесты без сети).
- Разработка через тесты; правила кода — глобальные правила владельца (функции до ~20 строк, без магических чисел,
  один файл — одна ответственность).
- Ядро `bot/core/` — копия ядра чекера. Правится только с решения владельца, отдельным коммитом «Ядро: …» и строкой
  в `JOURNAL.md` для `jw_core`.
- Коммиты — по-русски, без `Co-Authored-By` и прочих приписок.
- Готовые боты (сайт-чекер, бот канала, загрузчик) — только чтение.
- После этапа — запись в `JOURNAL.md` (не длиннее 300 строк, старое удаляется) и блок в `HANDOFF.md` (только
  последняя передача).
