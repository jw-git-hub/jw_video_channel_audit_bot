# Памятка владельцу: @jw_video_channel_audit_bot

Адрес, пользователь и путь сервера здесь не пишутся — репозиторий публичный. Они в `deploy/deploy.local.env`
на Маке. Ниже «папка бота» — путь оттуда (`DEPLOY_PATH`), в командах — всегда в кавычках.

## Команды бота

| Команда | Кто | Что |
|---|---|---|
| `/start` | все | приветствие и абзац согласия; `/start <метка>` записывает источник |
| `/lang` | все | язык |
| `/about`, `/order` | все | кто сделал, как заказать |
| `/stats` | вы | учёт по меткам за 7 и 30 дней, расход квоты YouTube за сутки |
| `/channel @имя` | вы | аудиты канала за 20 дней: когда, откуда человек, из кэша ли, было ли предложение |
| `/forget <Telegram ID>` | вы | удалить данные человека по его просьбе |

Ссылки с меткой: `https://t.me/jw_video_channel_audit_bot?start=channel` — канал, `…?start=site` — сайт,
`…?start=grp_danang` — группа Дананга и так далее: латиница, цифры, `_` и `-`.

## Сервер — один раз

1. Docker — если его ещё нет (ставит тот бот, что выкладывается первым):
   ```bash
   sudo apt update && sudo apt install -y docker.io docker-compose-v2
   sudo usermod -aG docker "$USER"   # затем выйти и зайти по SSH заново
   ```
2. Репозиторий — вне папок Syncthing (если папки бота ещё нет):
   ```bash
   git clone https://github.com/jw-git-hub/jw_video_channel_audit_bot.git "<папка бота>"
   ```
3. `.env` — только руками и только здесь; папка `data` — пользователю контейнера (uid 10001):
   ```bash
   cd "<папка бота>"
   [ -f .env ] || cp .env.example .env   # уже есть — остаётся как есть
   chmod 600 .env && nano .env           # BOT_TOKEN, YOUTUBE_API_KEY, ADMIN_ID
   mkdir -p data && sudo chown 10001:10001 data
   ```
4. Первая выкладка — с Мака: `deploy/deploy.sh`.

Защиты сети, как у чекера, здесь нет: бот не ходит по присланным адресам — только в Google API и Telegram
(ТЗ, раздел 10).

## Выкладка и откат

- С Мака, из папки проекта: `deploy/deploy.sh` — выкладывает то, что уже в GitHub.
- Откат: `deploy/deploy.sh <sha прошлого коммита>` (`git log --oneline`).
- Выкладка ходит по домашней сети: в `deploy.local.env` — домашний адрес сервера. Остановилась с сообщением
  «нет связи с сервером» — проверьте, что сервер включён и Мак дома, в той же сети, и повторите. Из поездки —
  подставьте в `deploy.local.env` адрес сервера в Tailscale вручную.

## Жизнь бота

- Состояние: на сервере `cd "<папка бота>" && docker compose ps`.
- Журнал: `docker compose logs --tail 100 bot`. Каналов в нём нет — только номер аудита, метод и ответ Google.
- Открыть бота всем: в `.env` на сервере `OPEN_TO_ALL=true`, затем `docker compose up -d`.
- Лимиты: `USER_DAILY_LIMIT`, `GLOBAL_DAILY_LIMIT`; потолок квоты — `API_UNITS_DAILY`. В `.env`, затем
  `docker compose up -d`.
- ID и @имя каналов стираются из базы через 20 дней. Копии базы — `data/backups/`, по одной в сутки, 7 последних.
- Просьба удалить данные: человек пишет вам в личку → `/forget <его Telegram ID>` в течение 7 дней. Копии базы
  сотрутся сами через 7 дней.

## Сообщения от бота вам

| Сообщение | Что делать |
|---|---|
| «Google отклонил ключ YouTube» | ключ удалён, ограничен не тем API или проект отключён: новый ключ в своём проекте Google Cloud (только YouTube Data API v3) → `.env` → `docker compose up -d`; причина — в журнале, `reason` |
| «Квота YouTube кончилась» | ждать полуночи по тихоокеанскому времени (14:00–15:00 по UTC+7); если часто — `/stats`: наплыв людей или чужие @имена подряд |
| «Бот потратил … единиц квоты — это свой потолок» | то же; если Google дал больше квоты — поднять `API_UNITS_DAILY` |
| «Сработал общий потолок» | `/stats`: наплыв людей — поднять `GLOBAL_DAILY_LIMIT`; всё с одной метки — разобраться с источником |
| «Ответ YouTube не той формы» | YouTube поменял ответ: нужен разработчик; в журнале — метод и номер аудита |
| «Полоса не загрузилась» | бот повторит загрузку сам в течение часа, до тех пор шапка — строкой |

## Если ключ утёк

1. Токен бота: @BotFather → `/revoke` → новый токен в `.env` на сервере → `docker compose up -d`.
2. Ключ YouTube: удалить в Google Cloud, выпустить новый с тем же ограничением → `.env` → `docker compose up -d`.
3. Если секрет попал в git: не «удалять следующим коммитом» — сначала перевыпустить ключ, потом разбираться
   с историей.
